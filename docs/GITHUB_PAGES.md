# Бесплатное размещение на GitHub Pages

1. Владелец создаёт публичный репозиторий `OnlyVybe/OnlyVybe.github.io` или подтверждает другой целевой репозиторий.
2. Содержимое этой папки публикуется в выбранный репозиторий владельцем. Автоматический push не выполняется.
3. В GitHub открыть Settings → Pages и выбрать GitHub Actions.
4. Workflow `.github/workflows/pages.yml` выполнит install, typecheck, build и публикацию `dist`.
5. Проверить адрес `https://onlyvybe.github.io/` после первого успешного запуска.
6. Включить Enforce HTTPS в Settings → Pages, если GitHub Pages предлагает эту настройку.

Репозиторий должен быть публичным для бесплатного GitHub Pages в обычном режиме. На дату подготовки целевой репозиторий отвечал HTTP 404, поэтому сайт не считается опубликованным.

## Мониторинг 0 ₽

Владелец может самостоятельно добавить URL `https://onlyvybe.github.io/` в бесплатный мониторинг UptimeRobot. Регистрация и подключение выполняются владельцем; сайт не хранит ключи мониторинга.
